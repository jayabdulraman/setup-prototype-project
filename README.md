# setup-prototype-project

An agent skill that turns an idea into a working, shareable web app prototype (Next.js + Tailwind + shadcn/ui, IndexedDB first, deployed on Vercel). See [`SKILL.md`](./SKILL.md) for the full workflow.

## Install

Clone into your agent's skills folder, e.g. for Claude Code:

```bash
git clone https://github.com/jayabdulraman/setup-prototype-project ~/.claude/skills/setup-prototype-project
```
